# Requirements for PIO_Document_Sorter.py
#
# The script runs without any of these (it will just skip the PDF merge and
# tell you what to install). For the drawings merge you need ONE of the two
# PDF libraries below - pikepdf is recommended because it repairs many of the
# "this file cannot be merged" PDFs that Bluebeam also chokes on.

pikepdf>=8.0      # recommended - qpdf based, handles damaged/encrypted PDFs
pypdf>=4.0        # pure-python fallback (used only if pikepdf is missing)

# tkinter (the folder-picker windows) ships with the standard python.org
# installer on Windows, so it does not need to be listed here.
